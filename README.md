# Vue Todo App

Todo application built with Vue 3 and Vite.

---

## Stack

- Vue 3
- Vite
- JavaScript
- localStorage

---

## Features

- Create todos
- Edit todos
- Delete todos
- Toggle completed state
- Persist data in localStorage

---

## Installation

```bash
git clone https://github.com/azamxvit/vue-todo-app.git
cd vue-todo-app
pnpm install
pnpm dev

---

## Usage

Open in browser:

http://localhost:5173
